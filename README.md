# APM32F035_SDK
Official software development kit for Geehy APM32F035 microcontrollers.

## Current version

- SDK version: V1.2.1
- Supported device: APM32F035
- Official package date: February 10th, 2025
- Release notes date: October 30th, 2026
- Official download: [GAPM32F035_SDK_V1.2.1.rar](https://www.geehy.com/uploads/tool/APM32F035_SDK_V1.2.1.rar)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
